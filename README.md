# لمّة العيلة 🎉

مكتبة ألعاب للعيلة في التجمّعات، بالعربي المصري.

**العبها دلوقتي:** https://sayedfares.github.io/lammet-el-eila/

النسخة دي فيها الخمس ألعاب اللي بتتلعب على موبايل واحد. ألعاب الأوضة (التلاتة الأخيرين) محتاجين تشغيل السيرفر على جهازك (شوف «التشغيل» تحت).

| اللعبة | بتتلعب إزاي |
|---|---|
| 🎉 لمّة العيلة | أسئلة وألغاز وتحديات وأسئلة عن العيلة، بعجلة حظ (فرق، موبايل واحد) |
| ⚡ صح ولا غلط | جمل سريعة في وقت محدد (فرق، موبايل واحد) |
| 🤳 على الجبهة | الموبايل على الجبهة وميّله لتحت لو عرفت الكلمة (فرق، موبايل واحد) |
| 📜 كمّل المثل | أول المثل الشعبي والفريق يكمّله (فرق، موبايل واحد) |
| 🤔 فزّورة إيموجي | خمّن المثل أو الحكاية من الإيموجي (فرق، موبايل واحد) |
| 🤥 كدّاب ولا بجد؟ | كل واحد بموبايله: ألّف إجابة غلط ودوّر على الصح (أوضة) |
| 🔪 مين القاتل؟ | زي أمونج أس: بريئين ومهام وقتلة واجتماعات وتصويت، كل واحد بموبايله (أوضة، ٤ لاعيبة أو أكتر) |
| 🎭 اتخبّى واتنكّر | زي هايد أونلاين: المخبّي يتحوّل لحاجة في الأوضة والباحثين يخمّنوا (أوضة، ٢ لاعيبة أو أكتر، عدد الباحثين بتختاره) |

## التشغيل

```bash
python server.py
```

- على الكمبيوتر افتح `http://localhost:8000`.
- من الموبايلات افتح الرابط التاني اللي بيظهر (لازم كل الأجهزة على نفس الواي فاي).
- أول مرة ويندوز ممكن يسأل عن الـ Firewall: اسمح للشبكات الخاصة (Private) بس.

ألعاب الموبايل الواحد بتشتغل كمان لو فتحت `index.html` على طول، من غير سيرفر.
ألعاب الأوضة («كدّاب ولا بجد؟» و«مين القاتل؟» و«اتخبّى واتنكّر») بس هي اللي محتاجة السيرفر.

## الملفات

- `js/content.js`: كل الأسئلة والألغاز والتحديات والأمثال والكلمات. ضيف عليها براحتك.
- `data/bluff.json`: أسئلة «كدّاب ولا بجد؟».
- `js/core.js`: الأصوات، والمؤقّت، والعجلة، والاحتفال، والفرق.
- `js/games/`: ملف لكل لعبة.
- `server.py`: بيعرض الملفات وبيدير الأوض (بايثون عادي من غير تسطيب).

## أونلاين على Render (ببلاش)

1. ارفع المشروع على GitHub (الريبو ده).
2. على render.com: **New → Blueprint** → اختار الريبو → **Apply**. (الإعداد جاهز في `render.yaml`.)
3. بعد دقيقتين هيطلعلك رابط `https://lammet-el-eila.onrender.com` (أو قريب منه). ابعته للناس.

الباقة المجانية بتنام بعد ~١٥ دقيقة من غير استخدام (أول فتحة بعدها بتاخد حوالي دقيقة)، والأوضة بتتمسح لما ينام.
